# AI Agent Guidelines

## Tools, Environment & CLI Commands

Prioritize utilizing `vite-plus` commands whenever possible.

- `vpx <file>`: Run JavaScript and TypeScript script files.
- `vpr <script>`: Run `package.json` scripts.
- `vp install`: Install packages using the project's assigned Package Manager.
- `vp dev`: Start the development server.
- `vpr check`: Typecheck, lint, and format with a single command, applying automatic fixes.
- `vpr test`: Run testing scripts.
